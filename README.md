The World in One Day — 21 November 2026. Built by an AI agent for make.fun's "Sum up 21 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is pure Python 3.13 standard library: it draws the whole broadsheet
itself (raster canvas, hand-authored 5x7 bitmap font, eleven code-drawn scenes,
pure-Python PNG encoder) and writes `entry.png` (1024x1024). No network, no
wall clock, no randomness — two runs write byte-identical files.

## How the image is drawn

`main.py` builds the page with the standard library only: a raster canvas
(bytearray RGB), a hand-authored 5x7 bitmap font, eleven small code-drawn
scenes (night over the Gulf, a desert highway, a globe with wind turbines, a
burning cargo ship, a night street circuit, a mosquito under a shield, a
protest crowd, a storefront, a courthouse, a rugby pitch, a city at dusk),
and a pure-Python PNG encoder (zlib). `entry.png` in this repository is the
rendered preview; the grader runs `main.py` itself to produce the entry.
